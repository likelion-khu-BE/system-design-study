# 발표자료

```text
발표자료/
├── README.md          # 발제문
└── 발표자료.pptx       # 시각 자료(PPT, HTML 등 자유 형식)
```

발표자는 해당 주차의 학습을 책임지고 이끄는 리더입니다. 챕터 전체를 다른 참여자에게 가르친다는 관점으로 이해하고, 단순한 내용 요약을 넘어 문제 상황에서 설계가 발전하는 흐름과 각 선택의 이유를 설명할 수 있어야 합니다.

참여자가 설계의 근거와 트레이드오프를 이해하도록 돕고, 내용 전반에 관한 질문에 답하며 토론을 이끌 수 있는 수준으로 준비합니다. 이 목적 안에서 발제문과 시각 자료의 내용, 구성, 형식은 자유입니다.

발표자는 해당 주차 학습노트를 작성하지 않아도 됩니다.
