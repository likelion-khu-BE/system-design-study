# 학습노트

```text
학습노트/
├── 김우진.md
├── 신선우.md
├── 장찬욱.md
└── ...
```

`이름.md`로 제출합니다.

학습노트는 챕터를 읽고 이해한 내용을 자신의 언어로 남기며, 세션에서 질문하고 토론할 준비를 하는 기록입니다. 책의 내용을 그대로 옮기기보다 핵심 내용을 자신의 언어로 다시 설명하고, 이해한 부분과 아직 남은 질문이 드러나는 기록을 지향합니다.

세션이 끝난 뒤 다시 읽어도 핵심 개념과 당시의 고민을 떠올릴 수 있는 기록을 목표로 합니다. 이 목적 안에서 분량과 구성은 자유입니다.

발표자는 해당 주차 학습노트를 작성하지 않아도 됩니다.
