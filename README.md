### A. 학습노트

학습노트는 챕터를 읽고 이해한 내용을 자신의 언어로 남기며, 세션에서 질문하고 토론할 준비를 하는 기록입니다. 책의 내용을 그대로 옮기기보다 핵심 내용을 자신의 언어로 다시 설명하고, 이해한 부분과 아직 남은 질문이 드러나는 기록을 지향합니다.

세션이 끝난 뒤 다시 읽어도 핵심 개념과 당시의 고민을 떠올릴 수 있는 기록을 목표로 합니다. 이 목적 안에서 분량과 구성은 자유입니다. `학습노트/` 폴더에 `이름.md`로 제출하며, 해당 주차 발표자는 작성하지 않아도 됩니다.

### B. 발표자료

발표자는 해당 주차의 학습을 책임지고 이끄는 리더입니다. 챕터 전체를 다른 참여자에게 가르친다는 관점으로 이해하고, 단순한 내용 요약을 넘어 문제 상황에서 설계가 발전하는 흐름과 각 선택의 이유를 설명할 수 있어야 합니다.

참여자가 설계의 근거와 트레이드오프를 이해하도록 돕고, 내용 전반에 관한 질문에 답하며 토론을 이끌 수 있는 수준으로 준비합니다. `발표자료/` 폴더에 발제문 `README.md`와 시각 자료 1개를 제출하되, 이 목적 안에서 내용과 구성, 시각 자료의 형식과 파일명은 자유입니다.
