페이스북의 주변 친구 기능의 아키텍처를 알아보자

<요구 사항>
사용자는 본인의 위치를 주변 친구들에게 송신하고,
주변 친구들의 위치를 30초 주기로 수신 한다.

한 사용자당 최대 5000명 평균 400명의 친구를 갖는다.
주변 친구의 정의는 5마일 이내 위치하고 활성 상태인 친구이다. (친구의 10%정도가 해당)

사용자의 이동 이력을 데이터 베이스에 저장한다 (기계 학습 등을 위한 데이터 수집용)

<네트워크 아키텍처>
p2p : 클라이언트 끼리 데이터 직접 송수신 하기

클라이언트-서버 : 클라이언트는 공용 서버와 정보를 송수신 하고, 
서버가 주변 친구들을 찾아 정보를 전달해주는 역할을 한다

p2p는 각 사용자의 스마트폰에서 주변 친구 로직을 계산해야 하므로 전력 소비가 심해 사용자 부담이 크다. 인프라 비용을 들여 서버를 개설하는 것이 자연스럽다.


<프로토콜>
http : 클라언트는 30초 주기로 본인 위치를 post, 주변 친구 위치를 get 한다.
클라이언트가 요청해서 서버의 정보를 get 할 수 있으므로, 주변 친구가 아닌 모든 친구 정보를 조회한다. 매 통신마다 TCP 연결/HTTP 헤더를 만드는 오버헤드가 발생한다.

웹소켓이 뭐지?
클라이언트와 웹소켓 서버는 1번 handshake 연어어결 이후 '양방향' 데이터를 교환하는 유상태 프로토콜이다.
장점 :
최초 연결 이후 가벼운 데이터 프레임만 송수신 (latency 감소)
서버가 클라이언트의 요청 없이도 데이터를 보낼 수 있다.
주의점 :
유상태 프로토콜 이므로 기존 서버 제거시 로드 밸런서에게 알려야함
클라이언트의 비정상 종료를 감지해야함
유상태성 때문에 확장이 까다롭다

30초마다 위치정보를 송수신 한다는 점, 지연시간 등을 고려하여 웹소켓을 사용한다.

로드벨런서가 트래픽 분산을 고려해 적절하게
클라이언트 한명당 하나의 웹소켓 서버 프로세스를 할당한다
클라이언트가 활성화~종료 까지 연결이 지속된다.

<데이터 베이스>
사용자 프로필, 친구 관계가 담긴 사용자 데이터 베이스
관계형 데이터 베이스로 확장시 사용자 ID 기준으로 샤딩

사용자 위치 정보가 저장된 위치 이동 이력 데이터 베이스 (주변 친구 기능과 연관 x)

<Redis>
클라이언트당 하나의 웹소켓 서버 프로세스가 할당 되었다.
친구 웹소켓 서버와 위치 정보를 전달할 통로가 필요하다.

Redis가 뭐지?
Redis는 RAM, CPU, NIC 을 자원으로 쓰는 프로세스로
디스크가 I/O 사용이 없기에 비영속적이고
속도가 마이크로 단위로 빠르다. 
CPU는 싱글 스레드로 1개 코어로 명령을 순차 처리한다
NIC(네트워크 카드) 는 Redis가 전송할수 있는 데이터의 크기를 결정한다.

클라이언트 한명이 야기하는 송수신 시간 복잡도는 O(N) (활성 친구 수 N) 이므로
Redis를 사용하는 이유는 수억명의 트래픽을 in-memory 기반으로 빠르게 처리하기 위한 걸로 보인다.

페이스북 주변 친구 기능에선 초당 1400만 건의 위치 정보 업데이트를 가정하고 있다.
하지만 Redis가 빠르기 때문에 오히려 병목이 되는지점은 NIC(초당 데이터 전송량 = 10만) 이 된다.

주변친구 기능에선 1400만 / 10만 = 140개의  Redis 프로세스 노드 자원을 구축한다. 
Redis 노드당 (1000만 / 140대) => 7만 유저 채널 대응

클라이언트 A - (1:1)- 웹소켓 서버 A - (1 : N) -  Redis 노드 X
                                                       ㄴ Redis 노드 Y - 웹소켓 서버 B - (1:1) 클라이언트 B


<웹소켓 서버 to Redis 노드> 
웹소켓 서버와 Redis 서버는 resp라는 프로토콜로 통신한다.
지속연결, 양방향 push 의 특성을 가진다.
웹소켓 프로토콜의 서버-서버 버전같다.

수신자는 송신자를 구독하고 구독자들에게 정보를 push하는 방식이
Redis를 매게로 이루어진다.

Redis Pub/sub:  
redis 내 해시 테이블 자료구조다
key = 송신자 채널명 : value = 수신자 웹소켓 링크드리스트

구독 - publish - 구독해지 과정이 일어난다.
